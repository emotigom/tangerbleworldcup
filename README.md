# Tangible World Cup Map Editor

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Tangible Coding World Cup 활동을 위한 축구 맵 편집 및 플레이 웹 도구입니다.

## 사용 방법

1. 이 저장소를 내려받습니다.
2. `index.html`을 웹 브라우저에서 엽니다.
3. 시작 지점, 골대, 수비수, 장애물을 배치하고 맵을 저장하거나 불러옵니다.

별도의 빌드나 서버 설치가 필요하지 않습니다.
